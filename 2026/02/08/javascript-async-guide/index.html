JavaScript 异步编程入门指南

为什么需要异步编程

JavaScript 是单线程语言，这意味着它一次只能执行一个任务。如果所有操作都是同步的，那么像网络请求、文件读取这样的耗时操作就会阻塞主线程，导致页面卡顿。

异步编程就是为了解决这个问题而生的。
