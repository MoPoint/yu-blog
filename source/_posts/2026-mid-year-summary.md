## 写在前面

转眼间 2026 年已经过半。每到年中，我习惯停下来回顾一下这半年的收获与遗憾，为下半年的规划调整方向。

<!-- more -->

## 技术上的成长

### 掌握了什么

这半年在技术方面，我重点投入了以下几个方面：

1. **前端框架深入** — 将项目从 Vue 2 迁移到了 Vue 3 + Composition API，对响应式原理有了更深的理解
2. **后端能力拓展** — 学习了 Node.js 和 Express 框架，能够独立搭建完整的 RESTful API
3. **DevOps 入门** — 掌握了 Docker 和 Docker Compose 的基本使用，配置了 CI/CD 流水线
4. **博客搭建** — 用 Hexo + Fluid 搭建了个人博客，养成了写作的习惯

### 有待提升的方面

- 算法和数据结构的学习还不够系统
- 阅读开源项目源码的习惯还没完全养成
- 技术文章的产出频率只有每月 2-3 篇，希望下半年能提高到每周 1 篇

## 工作上的思考

### 做得好的地方

- 完成了两个重要项目的交付
- 在团队中承担了更多的技术设计工作
- 开始参与 Code Review，对代码质量有了更高的要求

### 需要改进的

- 跨部门沟通的效率还需要提升
- 需求评审阶段应该更多考虑扩展性
- 技术债务的清理需要更主动

## 生活的点滴

这半年在生活上也有一些积极的改变：

- 保持了每周 3 次运动的习惯
- 读完了 8 本书（技术类 5 本，非技术类 3 本）
- 开始学习做饭，生活质量提升了

## 下半年的计划

### 技术目标

1. 深入学习 TypeScript 的进阶用法
2. 完成一个小型开源项目
3. 博客文章达到每周 1 篇的更新频率

### 个人目标

1. 读完 12 本书（每月 2 本）
2. 参加一次线下技术交流活动
3. 学习一门新语言（计划学 Rust）

## 结语

回顾这半年，有收获也有遗憾，有进步也有不足。重要的是保持持续前进的节奏，不需要每天都有巨大的突破，但求每天都在进步。

希望年底回顾时，能看到一个更好的自己。
